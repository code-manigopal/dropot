PROMPT 40: Architecture Clarification
--------------------------------------------------------------------------------
so this is not an integrated storage? just a visual abstract as we can
access all things in one place?

HONEST ANSWER:
What users SEE: One shared ocean, all files together
What actually happens: Each person uploads to THEIR OWN Drive,
Firestore stores metadata/links, Dropot shows everything together in one UI

This is actually BETTER than true integrated storage:
- Files never leave uploader's own Drive
- No migration on member exit needed
- Stronger transparency identity
- No single point of failure

DECISION: Keep this architecture. Rename mental model from
"integrated storage" to "shared collection with distributed storage"
